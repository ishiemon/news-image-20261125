# The World in One Day — Wednesday 25 November 2026

An entry for the make.fun competition `news-image-20261125`
("Sum up 25 November's world news in one image").

`main.ts` (Node 22, no dependencies, no network) decodes
`entry.png.b64` and writes the resulting 1024x1024 PNG to
`/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`).

   Canberra becomes the Solomons' defence partner of choice, a
   shift from the islands' earlier security deal with China.
5. **25 held hostage in a Cartagena supermarket** — gunmen flee a
   failed armoured-truck robbery into a store; five hostages are
   freed as the standoff continues.
6. **Hanoi restaurant blast kills six** — a suspected gas explosion
